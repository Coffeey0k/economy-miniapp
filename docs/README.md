# Telegram Mini App для Paradise Reef

Показывает профиль игрока: баланс, место в топе, варны, профессию,
статистику игр, питомцев и купленные услуги — на основе твоей базы `paradise.db`.

## Структура
- `backend/main.py` — API на FastAPI, читает данные напрямую из `paradise.db`
  (той же базы, с которой работает бот)
- `frontend/index.html` — страница профиля, открывается внутри Telegram

Backend только **читает** базу — ничего не списывает и не начисляет.
Вся игровая логика остаётся в самом боте.

## Шаг 1. Помести backend рядом с базой бота
Backend должен видеть файл `paradise.db`. Проще всего — положить
`backend/main.py` и `requirements.txt` в ту же папку, где лежит бот
(или туда, куда бот сохраняет `paradise.db`), и указать путь через
переменную окружения `DB_PATH`, если база лежит не рядом.

## Шаг 2. Хостинг backend (бесплатно)
GitHub Pages/Netlify/Vercel подходят **только для фронтенда** (статика),
для Python-сервера нужен отдельный хостинг с поддержкой процессов:

| Сервис | Особенности |
|---|---|
| **Render.com** | Проще всего, бесплатный план "засыпает" после 15 мин простоя |
| **Railway.app** | Быстрый деплой из GitHub, есть бесплатный лимит по часам |
| **Fly.io** | Бесплатный тариф, чуть сложнее в настройке |
| **PythonAnywhere** | Просто для FastAPI/Flask, ограничения по трафику |

Быстрее всего — Render:
1. Залей папку `backend/` в GitHub-репозиторий
2. На render.com: New → Web Service → подключи репозиторий
3. Build command: `pip install -r requirements.txt`
4. Start command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
5. В Environment добавь переменную `BOT_TOKEN` (токен твоего бота)
6. База `.db` тоже должна лежать рядом (загрузи её в репозиторий или подключи volume)

## Шаг 3. Хостинг frontend (бесплатно)
1. Залей `frontend/index.html` в GitHub Pages / Netlify / Vercel
2. В `index.html` замени `API_URL` на адрес своего задеплоенного backend

## Шаг 4. Подключение к боту через BotFather
1. Напиши [@BotFather](https://t.me/BotFather) → `/mybots` → выбери бота
2. Bot Settings → Menu Button → укажи URL своего фронтенда
   (или команда `/newapp` для полноценного Mini App)
3. Готово — кнопка/меню будет открывать твой сайт внутри Telegram

## Важно про безопасность
Backend проверяет `initData` через HMAC-подпись (см. `validate_init_data`
в `main.py`) — это гарантирует, что запрос реально пришёл из Telegram
и относится к тому пользователю, который открыл приложение. Не убирай эту проверку.

## Важно про хостинг базы данных
Backend читает файл `paradise.db` напрямую с диска. Это значит, что backend
**обязательно должен работать на том же сервере/машине, где лежит база бота**
(либо база должна быть доступна ему по сети). Если планируешь хостить backend
на Render/Railway отдельно от бота — проще всего разместить там **и бота, и
backend вместе**, чтобы оба обращались к одному файлу `paradise.db`.

SQLite неплохо переносит параллельное чтение, но если бот и backend будут
одновременно активно писать/читать — возможны короткие блокировки. Для
профиля (только чтение) это не критично.
